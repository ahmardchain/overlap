# Spectrum UI

Chart component and kit adapted from https://github.com/arihantcodes/spectrum-ui, app/registry/charts/line-chart.tsx and chart-kit.tsx.
License: Apache-2.0, reproduced in public/licenses/spectrum-ui.txt.
Modifications: custom asset series/date ticks, missing-observation bands, null-preserving linear paths, CSS class adapters for Overlap. Reveal mask, active dots, tooltip, axes and plot surface originate in Spectrum UI.
